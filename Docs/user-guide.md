# Panduan pengguna

Pelanggan: katalog → daftar/masuk → keranjang → checkout → pickup/delivery dan Midtrans/COD → pantau Pesanan. Harga, ongkir, dan stok final dihitung server.

Admin: Dashboard untuk ringkasan; Produk untuk katalog/foto; Stok untuk adjustment beralasan; Pesanan untuk COD/fulfillment; Laporan untuk periode WITA dan CSV.

Jangan mengedit total order berbayar atau histori lewat database. Pembayaran masuk dengan stok bermasalah berstatus exception dan tidak boleh disamarkan menjadi unpaid.
